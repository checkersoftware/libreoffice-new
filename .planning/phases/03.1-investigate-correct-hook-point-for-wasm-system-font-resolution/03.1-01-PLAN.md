<objective>
Add filtering guards to the WASM font resolution hook in fontsubst.cxx so that it only fires for genuinely missing document fonts -- not for fonts with bundled metric-compatible substitutes and not for known LO internal default/UI fonts.

Purpose: Eliminate spurious JS font resolution calls that cause (a) unnecessary round-trips to the host for fonts LO never needs from the system, and (b) system fonts replacing bundled metric-compatible fonts, breaking text metrics and layout.

Output: Modified fontsubst.cxx with two new static helper functions and updated guard chain in the EMSCRIPTEN block.
</objective>

**Function 1: `hasMetricCompatibleBundledSubstitute`**

```cpp
// Check if the font has a bundled metric-compatible substitute.
// Mirrors the first 6 entries of aMetricCompatibleMap from PhysicalFontCollection.cxx
// (the core Windows -> Liberation/Carlito/Caladea mappings). The Bundes* reverse
// mappings are not needed here because those map TO Calibri/Cambria which are NOT
// bundled -- the forward direction would never match a request for "BundesSans".
static bool hasMetricCompatibleBundledSubstitute(
    const OUString& rFamilyName,
    vcl::font::PhysicalFontCollection* pCollection)
{
    static const std::pair<std::u16string_view, std::u16string_view> aMap[] = {
        { u"Times New Roman", u"Liberation Serif" },
        { u"Arial",           u"Liberation Sans" },
        { u"Arial Narrow",    u"Liberation Sans Narrow" },
        { u"Courier New",     u"Liberation Mono" },
        { u"Cambria",         u"Caladea" },
        { u"Calibri",         u"Carlito" },
    };

    for (const auto& [src, dst] : aMap)
    {
        if (rFamilyName.equalsIgnoreAsciiCase(OUString(src)))
        {
            // Only skip if the substitute is actually in the collection
            return pCollection->FindFontFamily(OUString(dst)) != nullptr;
        }
    }
    return false;
}
```

Note: This intentionally does a runtime `FindFontFamily` check on the substitute, so if for some reason a Liberation font is not actually bundled, the JS resolution is not blocked.

**Function 2: `isKnownDefaultFont`**

```cpp
// Fonts that LO looks up as internal defaults from VCL.xcu -- never resolve
// from the host JS environment. These are UI fonts, locale-specific defaults
// for scripts where we have adequate substitutes via fontconfig, and Windows-
// specific fonts that appear in default font lists but serve no purpose on WASM.
//
// CJK fonts (Source Han Sans, Noto Sans CJK, etc.) are deliberately NOT listed
// here. A CJK document genuinely needs a CJK font and should be allowed to
// fetch one from the host system.
static bool isKnownDefaultFont(const OUString& rFamilyName)
{
    static const OUString aDefaults[] = {
        u"Arial Unicode MS"_ustr,
        u"DejaVu Sans"_ustr,
        u"Lohit Devanagari"_ustr,
        u"Lohit Hindi"_ustr,
        u"Lucida Sans Unicode"_ustr,
        u"Mangal"_ustr,
        u"Segoe UI"_ustr,
        u"Tahoma"_ustr,
    };

    for (const auto& rDefault : aDefaults)
    {
        if (rFamilyName.equalsIgnoreAsciiCase(rDefault))
            return true;
    }
    return false;
}
```

**Integration into the EMSCRIPTEN block in `FindFontSubstitute`:**

Modify the existing `#ifdef EMSCRIPTEN` block (currently at lines 292-370) to insert the two new guards between the `FindFontFamily` check and the negative cache check. The new flow should be:

```cpp
#ifdef EMSCRIPTEN
    if (s_pFontCollection
        && !s_pFontCollection->FindFontFamily(rFontSelData.maTargetName))
    {
        OUString aFamilyKey = rFontSelData.maTargetName;

        // Skip fonts that have bundled metric-compatible substitutes.
        // Let the normal pipeline use Liberation Sans for Arial, etc.
        if (hasMetricCompatibleBundledSubstitute(aFamilyKey, s_pFontCollection))
        {
            SAL_INFO("vcl.fonts", "WASM: skipping \"" << aFamilyKey
                     << "\" -- metric-compatible bundled substitute available");
        }
        // Skip known LO internal default/UI fonts that appear in VCL.xcu
        // default font lists. These are not document fonts.
        else if (isKnownDefaultFont(aFamilyKey))
        {
            SAL_INFO("vcl.fonts", "WASM: skipping \"" << aFamilyKey
                     << "\" -- LO internal default font");
        }
        else if (s_aWasmNegativeCache.count(aFamilyKey))
        {
            SAL_INFO("vcl.fonts", "WASM font cache: negative hit for \""
                     << aFamilyKey << "\", skipping JS call");
        }
        else
        {
            // ... existing JS resolution code (unchanged) ...
        }
    }
#endif // EMSCRIPTEN
```

The existing JS resolution code inside the `else` block (the SAL_INFO log, resolveFontFromHost call, path splitting, registerFontFromVFS loop, negative cache insertion) remains UNCHANGED.

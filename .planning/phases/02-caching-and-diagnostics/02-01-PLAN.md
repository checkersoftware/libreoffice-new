<objective>
Replace the Phase 1 `s_aTriedFonts` set with a negative-only font cache keyed by family name + style hints, and add SAL_INFO diagnostic logging to the WASM font resolution flow.

**Why no positive cache:** Once a font is registered via AddTempDevFont, it lives in the PhysicalFontCollection. The caller (`PhysicalFontCollection::FindFontFamily`) finds it via `ImplFindFontFamilyBySearchName()` BEFORE `FindFontSubstitute()` is ever called again. The re-registration guard is the call chain itself.

Purpose: Eliminate redundant JavaScript font resolution calls and make the font resolution flow fully observable for debugging.
Output: Modified `fontsubst.cxx` with negative cache infrastructure and diagnostic logging -- all within the existing `#ifdef EMSCRIPTEN` block.
</objective>

Replace the current WASM block. The logic is simpler now -- no positive cache needed because the PhysicalFontCollection caller already handles re-registered fonts before FindFontSubstitute is called:

```cpp
#ifdef EMSCRIPTEN
    if (s_pFontCollection
        && !s_pFontCollection->FindFontFamily(rFontSelData.maTargetName))
    {
        WasmFontCacheKey aCacheKey{
            rFontSelData.maTargetName,
            rFontSelData.GetWeight(),
            rFontSelData.GetItalic(),
            rFontSelData.GetWidthType(),
            rFontSelData.GetPitch()
        };

        if (s_aWasmNegativeCache.count(aCacheKey))
        {
            SAL_INFO("vcl.fonts", "WASM font cache: negative hit for \""
                     << rFontSelData.maTargetName
                     << "\", skipping JS call");
            // Fall through to fontconfig substitution
        }
        else
        {
            SAL_INFO("vcl.fonts", "WASM font resolution: requesting \""
                     << rFontSelData.maTargetName << "\" from host"
                     << " (w=" << rFontSelData.GetWeight()
                     << " i=" << rFontSelData.GetItalic()
                     << " wd=" << rFontSelData.GetWidthType()
                     << " p=" << rFontSelData.GetPitch() << ")");

            OString aUtf8 = OUStringToOString(rFontSelData.maTargetName,
                                               RTL_TEXTENCODING_UTF8);
            char* pPath = resolveFontFromHost(aUtf8.getStr());
            if (pPath)
            {
                OUString aPath = OStringToOUString(
                    OString(pPath), RTL_TEXTENCODING_UTF8);
                free(pPath);

                OUString aFileURL = "file://" + aPath;
                SAL_INFO("vcl.fonts", "WASM font resolution: JS returned \""
                         << aPath << "\" for \""
                         << rFontSelData.maTargetName << "\"");

                if (registerFontFromVFS(aFileURL, rFontSelData.maTargetName))
                {
                    SAL_INFO("vcl.fonts", "WASM font resolution: registration "
                             "succeeded for \""
                             << rFontSelData.maTargetName << "\"");
                    // No positive cache needed -- font is now in PhysicalFontCollection,
                    // so FindFontFamily() in the caller finds it before we're called again.
                    return false;
                }

                SAL_WARN("vcl.fonts", "WASM font resolution: registration "
                         "failed for \"" << aFileURL << "\"");
                // Registration failed (corrupt file, bad format) -- cache negative per user decision
                s_aWasmNegativeCache.insert(aCacheKey);
            }
            else
            {
                SAL_INFO("vcl.fonts", "WASM font resolution: JS returned "
                         "empty for \"" << rFontSelData.maTargetName << "\"");
                s_aWasmNegativeCache.insert(aCacheKey);
            }
        }
    }
#endif // EMSCRIPTEN
```

**Critical correctness notes:**
- Use `rFontSelData.maTargetName` for cache key, NOT `maSearchName` -- JS resolver expects the original family name
- Return `false` after successful registration -- means "no substitute needed, font is directly available" so the caller's `ImplFindFontFamilyBySearchName()` finds the newly registered font
- Insert into negative cache in BOTH the JS-returns-null AND registration-failure branches
- Remove ALL references to `s_aTriedFonts` -- must not coexist with new cache
